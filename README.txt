NAINA TECHNOLOGIES — SEO BLOG STARTER

Files:
- index.html
- assets/naina-tech-logo.webp (your supplied logo, copied unchanged)

Run in VS Code:
1. Extract this ZIP.
2. Open the naina_seo_blog folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Internet is needed for Bootstrap CDN and the Unsplash topic images.

Before publishing:
- Confirm the canonical URL matches the final published blog URL.
- If your site already has a blog system, publish the article through that system instead of replacing your homepage.
- For a static website, upload the HTML and assets to a suitable blog path on your hosting server.
- The image URLs are external Unsplash images; download and host them locally if you need full control over availability.
- Update the contact button or contact details if needed.
